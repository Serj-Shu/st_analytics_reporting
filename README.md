### Что это?
Self-service интерфейс для выгрузки сводных аналитических отчетов из БД (любой).

### Для кого?
Аналитики различных бизнес-юнитов.

### Основной фреймворк под капотом
https://streamlit.io/

### Принцип работы
Пользователь выбирает фильтры, измерения и метрики. 
"Под капотом" формируется SQL-запрос в таблицу, которая закреплена за каждым разделом.
После выполнения запроса данные можно скачать в Excel для дальнейшей аналитики.

### Авторизация
По AD.
